# AirBnB Clone

This is a small Python command-line program for creating and saving rental
objects such as users and places.

## Start

Open a terminal in this folder and run:

```bash
python3 console.py
```

## Commands

```text
create User
show User <id>
all
update User <id> name Alice
destroy User <id>
quit
```

Objects are saved in `file.json`, so they are still available after restarting
the program.
