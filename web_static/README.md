# AirBnB clone - Web static

Static HTML/CSS prototype of the AirBnB clone front end: fake content, no
JavaScript, no data loaded from anywhere.

| Task | Files |
|---|---|
| 0. Inline styling | `0-index.html` |
| 1. Head styling | `1-index.html` |
| 2. CSS files | `2-index.html`, `styles/2-*.css` |
| 3. Zoning done! | `3-index.html`, `styles/3-*.css`, `images/` |
| 4. Search! | `4-index.html`, `styles/4-common.css`, `styles/4-filters.css` |
| 5. More filters | `5-index.html`, `styles/5-filters.css` |
| 6. It's (h)over | `6-index.html`, `styles/6-filters.css` |
| 7. Display results | `7-index.html`, `styles/7-places.css` |
| 8. More details | `8-index.html`, `styles/8-places.css` |

Rules followed: W3C valid HTML, CSS in `styles/`, images in `images/`, no
`img`/`embed`/`iframe` tags (images are CSS backgrounds), no `!important`, no
`id` selectors, no JavaScript. Open any `N-index.html` in a browser to view it.
